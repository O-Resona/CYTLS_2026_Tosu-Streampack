\# CYT 2026: Lazer Scramble

>\*\*请直接运行CYTLS\_Updater.exe，而不是tosu\*\*，以便检测数据更新，实时更新

\## 一、赛前准备（开播前 15 分钟）

\### 1. 选比赛

进入 \*\*Schedule\*\* 页 —— 页面会\*\*自动选中最近一场未开始的比赛\*\*。

若不对，到bracket页面选中负责播的比赛。



\### 2. 修正信息（如需）

进入 \*\*Bracket\*\* 页，右侧面板：

可以本地修改，但不会修改文件信息，可向host反馈



\---

\## 二、比赛中流程

\### BP 阶段（停留在 Mappool 页）

\- 一定要记得选\*\*先选方\*\*（红 / 蓝），之后pbp自动

\- 若识别有误，手动点击覆盖



\### 打图阶段

\- 玩家进图瞬间，页面\*\*自动切到 Playing\*\*



\### 打图结束

\- \*\*4 秒\*\*后分数条淡出 → 地图卡移动 → 聊天框出现

\- \*\*13 秒\*\*后自动切页：

&#x20; - 非决胜局 → 回 \*\*Mappool\*\*

&#x20; - 决胜局 → 切 \*\*Winner\*\*



\-转场错误再手动切换



\---

\## 三、常见问题

| 现象 | 处理 |

|---|---|

| 页面数据不动 | 刷新浏览器；确认 tosu 在运行 |

| 分数不更新 | 检查 osu 是否真在打图、tosu 是否连上 |

| BP 自动识别错 | 手动点一次覆盖，后续自动流程以次为准修正 |

| 切页卡住 | 刷新页面；或手动点左侧导航 |

| OBS 里绿幕没抠干净 | 色度键键颜色改为 `#00FF00`，相似度调高 |
